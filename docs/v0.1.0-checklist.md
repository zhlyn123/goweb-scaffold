# v0.1.0 Checklist

本清单用于确认脚手架是否达到第8周稳定化交付标准。

## 已完成范围

- [x] Gin HTTP 服务可启动。
- [x] 配置加载支持 YAML 和 `GOWEB_` 环境变量覆盖。
- [x] zap 结构化日志可用。
- [x] request id、access log、recovery 中间件可用。
- [x] 统一成功和错误响应结构可用。
- [x] PostgreSQL + GORM 连接封装可用。
- [x] goose migration 可执行 up/down/status。
- [x] Redis 客户端封装可用。
- [x] `/health/live` 可用。
- [x] `/health/ready` 检查数据库和 Redis。
- [x] `/metrics` 可供 Prometheus 抓取。
- [x] OpenTelemetry tracing 接入。
- [x] 用户注册、登录、当前用户接口可用。
- [x] 密码使用 bcrypt 哈希保存。
- [x] JWT 鉴权中间件可用。
- [x] RBAC 基础表、默认数据、权限校验可用。
- [x] 登录限流、请求体大小限制、CORS 安全配置可用。
- [x] Dockerfile、docker-compose.yml、Makefile 可用。
- [x] OpenAPI 文档可用。
- [x] 核心链路已有单元测试或 API 测试覆盖。
- [x] 模块开发指南、配置说明、错误码说明已补充。

## 发布前检查

```bash
make fmt
make test
make openapi
docker compose up --build
```

如需运行 repository 集成测试，先启动测试数据库，再执行：

```bash
make test-integration TEST_DATABASE_DSN="host=localhost port=5432 user=postgres password=postgres dbname=goweb_scaffold sslmode=disable TimeZone=Asia/Shanghai"
```

## 暂不纳入 v0.1.0

- Kubernetes 模板。
- CI/CD 流水线。
- 审计日志。
- 多租户。
- OAuth2 / OIDC。
- 分布式限流。
- 代码生成器。
